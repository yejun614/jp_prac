# メモ帳 — 일본어 메모장

Vite + React로 만든 웹 메모장입니다. 일본어 · 한국어 IME를 의존성 없이 순수 JS로 직접 구현했습니다.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build
```

## 페이지
| 경로 | 내용 |
| --- | --- |
| `/` | 메모장 |
| `/typing` | 일본어 타자연습 |

라우팅은 `react-router`(BrowserRouter)를 사용합니다. 정적 호스팅에 배포할 때는 모든 경로를 `index.html`로 돌려주는 SPA fallback 설정이 필요합니다.

## 메모장 기능
- **입력 모드**: 영어 / 일본어 / 한국어 (`Alt+1/2/3`, `Alt+\`` 순환)
- **일본어 IME** (`src/ime/`): 로마자→가나, 문절 분할, 한자 변환, 후보 창, 변환 학습, F6~F10 문자 종류 변환
  - 내장 미니 사전 + 설정(⚙)에서 SKK 사전(M/ML/L) 다운로드 또는 파일 불러오기 (IndexedDB 저장)
- **한국어 IME**: 두벌식 오토마타 (겹받침, 이중모음, 자모 단위 백스페이스)
- **탭 / 화면 분할**: 창마다 탭, 좌우·상하 분할, 탭을 끌어 다른 창이나 가장자리에 놓기, 경계선 드래그로 크기 조절
- **서식**: 굵게, 기울임, 밑줄, 취소선, 글자색, 형광펜, 제목, 목록, 인용, 왼쪽·가운데·오른쪽 정렬
- **쓰기 방향**: 메모별 가로쓰기 / 세로쓰기(縦書き)
- **내보내기**: `.md` / `.txt` 다운로드, `.txt`/`.md` 파일 열기
- 글꼴: Pretendard JP (`pretendard-jp` 패키지로 자체 호스팅), 모든 메모는 localStorage에 자동 저장

> OS 입력기(한/영)가 켜져 있으면 그 입력이 우선합니다. 앱 IME를 쓰려면 OS 입력기를 영문으로 두세요.

## 타자연습 기능 (`/typing`)
- 모드: 가나(ひらがな/カタカナ/둘 다, 30문제) · 단어(15문제) · 문장(8문제)
- 문제 카드: **한자 문장 → 히라가나/가타카나 읽기 → 입력할 로마자** 순서로 표시, 입력한 부분은 흐리게
- 여러 로마자 표기 인정: shi/si/ci, tsu/tu, chi/ti, sha/sya, ん = n/nn/n', っ = 자음 중복/xtu 등
  (입력한 표기에 맞춰 로마자 가이드가 바뀜)
- 다음 키를 표시하는 화면 키보드, 오타 시 흔들림 표시
- 표시 옵션: 히라가나/가타카나 표시·가리기, 후리가나(한자 위 읽기) 표시·미표시, 로마자 표시·가리기, 화면 키보드 표시·숨기기(연습 중에도 전환 가능)
  - 가린 줄에는 입력한 부분만 보이고, 로마자를 가렸을 때 같은 자리에서 3번 연속 틀리면 다음 키를 힌트로 표시
  - 가리기 옵션을 켠 기록은 일반 기록과 따로 저장
- 타/분, 정확도, 시간, 오타 수, 자주 틀린 글자 · 모드별 최고 기록과 최근 10회 기록 저장

# メモ帳 — 일본어 메모장

Vite + React로 만든 웹 메모장입니다. 일본어 · 한국어 IME를 의존성 없이 순수 JS로 직접 구현했습니다.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build
```

## 기능
- **입력 모드**: 영어 / 일본어 / 한국어 (`Alt+1/2/3`, `Alt+\`` 순환)
- **일본어 IME** (`src/ime/`): 로마자→가나, 문절 분할, 한자 변환, 후보 창, 변환 학습, F6~F10 문자 종류 변환
  - 내장 미니 사전 + 설정(⚙)에서 SKK 사전(M/ML/L) 다운로드 또는 파일 불러오기 (IndexedDB 저장)
- **한국어 IME**: 두벌식 오토마타 (겹받침, 이중모음, 자모 단위 백스페이스)
- **탭 / 화면 분할**: 창마다 탭, 좌우·상하 분할, 탭을 끌어 다른 창이나 가장자리에 놓기, 경계선 드래그로 크기 조절
- **서식**: 굵게, 기울임, 밑줄, 취소선, 글자색, 형광펜, 제목, 목록, 인용, 왼쪽·가운데·오른쪽 정렬
- **쓰기 방향**: 메모별 가로쓰기 / 세로쓰기(縦書き)
- **내보내기**: `.md` / `.txt` 다운로드, `.txt`/`.md` 파일 열기
- 글꼴: Pretendard JP (`pretendard-jp` 패키지로 자체 호스팅), 모든 메모는 localStorage에 자동 저장

> OS 입력기(한/영)가 켜져 있으면 그 입력이 우선합니다. 앱 IME를 쓰려면 OS 입력기를 영문으로 두세요.
